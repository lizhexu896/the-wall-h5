# 墙 · THE WALL｜1940—1944

一个可以直接打开、也可以离线运行的单页 H5 深度报道，为新闻大赛参赛作品而做。

主题取自十二张历史资料照片：1940 年 6 月巴黎陷落、德军装甲纵队调往西线、大西洋壁垒的混凝土工事、1944 年 6 月的诺曼底，以及隆美尔在北非与西线的一组影像。全篇按「占领 → 装甲调动 → 浇筑要塞 → 沙漠与海岸 → 天空与船坞 → 登陆」六章，讲述一条海岸线如何被一寸一寸建成要塞，一个从沙漠调来的将军如何在这里做出最后的判断，以及这座要塞为何在几个小时里被撕开。

## 打开方式

**本地直接看**：双击 `index.html`，用 Chrome / Edge / Safari / Firefox 打开即可，不需要服务器、不需要联网。

**这个 `index.html` 是真正的单文件版**：十二张照片已经以 base64 内嵌在页面里（整份 1.7 MB），所以把它单独拷到桌面、发微信、丢进任何预览器，照片都不会丢。

**手机上查看**：把 `index.html` 放进任意静态目录（本地起个 `python -m http.server` 也行），用手机访问；

**投稿/部署**：只上传 `index.html` 一个文件即可，无构建步骤、无依赖安装。

```
news-h5/
├── index.html            单文件版（HTML + CSS + JS + 图片全部内联）← 用这个
├── index-external.html   外链图片版（HTML 只有 48 KB，需与 assets/ 同级）
├── assets/img/           12 张资料照片
├── README.md
└── preview.png           六屏预览图
```

> 如果之前出现「照片显示不了」，常见原因只有三种：把 `index.html` 单独拷走却没带 `assets/`、直接在压缩包预览里打开、或者预览器不解析相对路径。现在用单文件版 `index.html`，这几种情况都不会再出问题。
>
> `_tools/` 是开发时用来截图自检的脚本（Node + Python），与页面运行无关，投稿前可以直接删掉。

## 设计说明

- **色调**：近黑底 `#0b0c0e` + 米白字 `#efeae1` + 砖红强调 `#c0492f`，贴近旧报纸与档案照片的质感。
- **字体**：标题用衬线（Songti / SimSun / Noto Serif CJK），正文用系统无衬线；不加载任何网络字体，所以离线也不会掉字。
- **节奏**：封面满屏 → 导语（首字下沉）→ 章节头（轮廓数字 + 英文小标）→ 全幅图片 + 图注 → 引语 → 数据 / 资料框 → 时间线 → 结语。
- **档案模块**（第 04 章）：人物档案卡（`.bio`，两列 `<dl>`）、横向滑动的照片档案（`.gallery`，`scroll-snap` 卡片）、两栏对照（`.compare`，靠前部署 vs 纵深部署）。
- **资料模块**：每章配一个 `.factbox`（左侧红线的小资料框：停战之后的三件事 / 一辆虎式的账本 / 一座掩体是怎么修的 / 劳工的三种身份 / 登陆日的一些数字）。
- **两条补充线索**：第 03 章的「谁在浇筑」讲强制劳工与托特组织；第 04 章的「如果隆美尔赢了那场争论」是可展开的反事实推演（明确标注不是史实）。
- **时间线**：第 06 章有两套——「最初的二十四小时」按小时排 1944 年 6 月 6 日当天，「四年，一条线」排 1940—1944 的战略进程；文末附 `.notes` 注释五条与延伸阅读。
- **交互**：顶部阅读进度条、章节胶囊（进入新章节时短暂出现后自动隐藏）、右下角三个悬浮按钮——目录抽屉、正文字号三档（16 / 18 / 20px，会记住选择）、回到顶部；所有照片可点击放大（灯箱，支持 ← → 翻页、Esc 关闭）；第 04 章的档案卡片可以横滑，桌面端两侧有箭头、下方有圆点；「如果隆美尔赢了那场争论」是一段可展开的反事实推演。

## 技术要点

| 项目 | 做法 |
| --- | --- |
| 依赖 | **零**。无 CDN、无外链字体、无统计脚本；`index.html` 里十二张图以 base64 内嵌 |
| 体积 | `index.html` 1.7 MB（含全部图片）；外链版 48 KB + `assets/` 3.25 MB |
| 渐进增强 | 未启用 JS 时内容全部可见（入场动画只在 `html.js` 下生效） |
| 响应式 | 320px — 1920px；正文栏宽 720px，桌面端数据自动变四栏 |
| 无障碍 | 图片均有 `alt`；装饰元素 `aria-hidden`；尊重 `prefers-reduced-motion` |
| 兜底 | 图片加载失败显示文字占位；无 `IntersectionObserver` 时直接全部显示 |
| 打印 | `@media print` 转为白底黑字、隐藏悬浮控件、横向列表转为自动换行 |
| 性能 | 图片已按 1080px 宽、质量 80 重新编码；无字体请求、无网络请求 |

## 想改点什么

| 想改 | 位置 |
| --- | --- |
| 主色 | `:root` 里的 `--accent`（默认砖红 `#c0492f`） |
| 底色 / 字色 | `--ink` / `--paper` / `--muted` |
| 正文宽度 | `--col`（默认 720px） |
| 文字 | `<main>` 里按章节改，标题在 `.ch-head`，图注在 `figcaption` |
| 人物档案 | 第 04 章的 `.bio` 里的 `<dl>`，一行 `<dt>` + 一行 `<dd>` |
| 横滑卡片 | 第 04 章的 `.gallery`，一张卡一个 `<figure class="card">` |
| 两栏对照 | 第 04 章的 `.compare`，一栏一个 `<div class="col">` |
| 资料框 | 任意 `.factbox`，里面是 `<h4>` + `<ul>` |
| 注释 | 第 06 章末尾的 `.notes`，与正文里的 `<sup class="ref">N</sup>` 对应 |
| 目录 | 章节标题写在 `.ch-head h2`，目录会自动生成，不用手工维护 |
| 字号档位 | `index-external.html` 顶部脚本里的 `FS = [16, 18, 20]` |
| 反事实段落 | 第 04 章的 `<details class="whatif">`，默认折叠 |
| 图注 | 每张图的 `figcaption`，灯箱里显示的就是这段文字 |
| 换图 | 替换 `assets/img/` 下同名文件后，用 `index-external.html`；或让助手重新生成单文件版 |
| 阅读时长 | 封面 `.meta` 里的「阅读约 15 分钟」 |

## 图片来源与说明
